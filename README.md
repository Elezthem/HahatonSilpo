# AI Charity Connect

AI Charity Connect координує благодійну допомогу та демонструє агентний сценарій на базі офіційного MCP «Сільпо».

## Запуск

```bash
npm start
```

Відкрийте `http://localhost:3000`. Під час першого підключення натисніть «Підключити Сільпо» та завершіть OAuth 2.1 + PKCE у браузері.

## Deploy на Render

Станом на 27 серпня 2026 року Render має безкоштовний `Web Service` для Node.js, тож цей проєкт підготовлено саме під нього.

1. Завантажте код у GitHub-репозиторій.
2. У Render натисніть `New` → `Blueprint` або `Web Service`.
3. Підключіть репозиторій.
4. Якщо Render не підхопить `render.yaml` автоматично, вкажіть:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. Додайте environment variables:
   - `PUBLIC_BASE_URL=https://YOUR-APP.onrender.com`
   - `MCP_REDIRECT_URI=https://YOUR-APP.onrender.com/callback`

Після цього сайт відкриється по публічному URL Render. Якщо потрібен live OAuth/MCP-сценарій, redirect URI має співпадати з реальною адресою задеплоєного сайту.

Для повного MCP-сценарію в акаунті «Сільпо» має існувати активний кошик із налаштованим магазином, типом доставки й часовим слотом.

## Агентний сценарій

1. Благодійна організація створює запит із категоріями товарів.
2. `silpo_get_my_shopping_cart` повертає активний кошик.
3. `silpo_get_shopping_cart_by_id` дає магазин і контекст доставки.
4. `silpo_get_time_slots` перевіряє актуальність слота.
5. `silpo_find_products_batch` знаходить реальні товари для потреб фонду.
6. Після явного підтвердження `silpo_add_or_update_cart_products` змінює кошик.
7. `silpo_get_shopping_cart_by_id` повторно перевіряє результат.

Якщо активного кошика ще немає, прототип усе одно демонструє live MCP через безпечний read-only сценарій:

- `silpo_get_loyalty_info`;
- `silpo_get_my_food_restrictions`;
- `silpo_get_my_online_orders`.

Інтерфейс показує тільки факт виконання та агреговані кількості — без телефона, email, номера картки або інших персональних даних.

Перед записом повного demo створіть активний кошик, виберіть магазин/адресу та доступний часовий слот. Агент перевіряє слот, stock, крок кількості, виконує запис лише після підтвердження, повторно читає кошик і показує blocking validations та checkout links.

Інтерфейс показує журнал MCP-викликів. OAuth-токен зберігається лише на сервері у `.token-cache.json`, який виключено з Git.

## Походження даних

- Каталог, доступність, контекст доставки й кошик: офіційний MCP «Сільпо».
- Запити благодійних організацій: дані прототипу AI Charity Connect.
- RNS і прогноз списань: демонстраційна модель. Для production їй потрібен дозволений внутрішній потік даних про продажі, партії та строки придатності, яких публічний MCP наразі не декларує.

## Валідація

Гіпотеза пілоту: скоротити час від запиту фонду до підтвердженого плану з 30–60 до 5 хвилин. Запланований пілот: 1 магазин, 1 фонд, 2 категорії, 2 тижні. Метрики: час формування плану, покриття потреби фонду, кількість blocking cart errors, вартість потенційно врятованих товарів. Реальні результати мають бути додані лише після тестування — прототип не видає синтетичні числа за проведений експеримент.
